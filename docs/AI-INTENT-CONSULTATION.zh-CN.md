# 问题识别与专家会诊

> 下方真实模型和浏览器结果记录于 2026-09-25，针对当时的 Windows 源码环境；不是 2026-09-28 的 Mac 实机或新版下载包验证。v0.3.0 的下载入口和限制见 `PORTABLE.zh-CN.md`。

本次升级作用于 `D:\可爱鱼儿的选股指南`。

用户直接输入问题即可，例如“比较腾讯港股和茅台 A 股最近的走势和风险”。参考标的框可不填。默认“专家会诊”，也可以选快速或标准；完成后可继续追问“那它们的分红呢”。

## 执行流程

1. **问题识别**：由模型理解用户问的股票、市场、比较关系、时间范围与研究重点。简称通过只读股票目录工具查询，代码必须来自目录返回、用户明确代码或同会话已核验标的。当前明确提问优先于界面遗留标的。
2. **研究计划**：显示股票名称和代码、需要回答的问题及专业分工。识别不明确时先提出澄清问题；用户可在同一会话补充回答，无需重复原问题。模型服务失败会显示配置/网络问题，不会伪装成股票歧义。
3. **统一取证**：分别获取每只股票的行情和财务快照，使用已配置的 Tushare Token 自动接入 MCP。多股票证据携带所属证券、市场和唯一引用编号。
4. **专业研究**：会诊模式安排 32 个专业角色，相关角色优先；按证券市场和实际数据跳过无法开展的工作，最多 3 个角色同时运行。快速和标准分别最多选择 3、11 个专业角色。
5. **多空互评**：多头、空头先独立论证，再各阅读对方初轮观点作一次回应。双方使用固定的同轮意见，结果不依赖完成先后；回应最多一轮，避免无限讨论。回应失败时标注限制并保留初轮论证。
6. **风险与结论**：独立风险审查员阅读专业意见和多空交流；研究总编汇总分歧、证据、数据缺口与后续核验。多名角色的相同观点不被当作多份独立证据。

会诊总计 36 个角色（32 专业 + 多头 + 空头 + 风险审查 + 总编），实际模型请求数还包含入口识别、多空回应及最多一次引用修正。并非 36 个进程同时请求数据。

## 会话与记忆

“它”“这两只”等指代使用同会话最近研究的标的；多股票比较也保留标的列表。新研究清空该会话上下文。澄清问题保留原始提问，便于直接补充市场或代码。长期记忆沿用用户主动保存的机制，仅包含最终研究观点及来源，不保存模型思考。

## 边界

- 每次最多 4 只 A 股/港股证券；超过上限提示缩小范围，不截掉多余股票。
- 暂未取得新闻、公告、行业或宏观数据时，对应角色显示数据缺口；不会编造最新事件。
- 无具体标的的全市场咨询目前会提示补充范围或具体证券，不能替代完整市场扫描。
- 专家会诊耗时和模型用量高于快速模式；可以中途停止，包括入口识别和数据采集阶段。
- 股票目录受 Tushare 权限与网络影响，目录不足时可补充明确代码。
