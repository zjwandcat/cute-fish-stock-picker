## 修复原因

1. 原先只读取标的框，未从提问识别股票；现支持股票池中的名称以及正文中的代码，明确区分 A/H，歧义不随意匹配。
2. 前端轮询使用了不存在的 `/progress`，已改为 `/status`，失败时也展示角色状态和具体原因。
3. SDK 打包后运行时定位失效；现显式定位本地 Harness 可执行文件。构造或启动失败时允许兼容回退；已发出的模型轮次不会因网络失败自动重复。
4. 原先输出预算可能被思考内容耗尽；预算调整为 4,096 token，DeepSeek 研究请求关闭思考输出，不把隐藏推理作为最终答案。
5. 缺失新闻被模型引用为 `[E9]`，造成最终答复被拒绝。现将缺口与可引用证据分开；错误引用最多修正一次，持续虚构引用仍拒绝。
6. MCP 不再读取旧设置中的 URL，只由本机 Tushare Token 生成官方地址。
7. `3001` 原先驻留昨晚的旧后端，已替换为新版。启动时比较构建标识，避免复用不同版本；修复 Windows 重复启动时的句柄退出异常。

“清除已保存的模型 API Key”仅在勾选并保存后删除本机模型密钥；不撤销服务商的 Key，也不删除 Tushare Token 和长期记忆。不勾选且输入框留空会保留原密钥。
