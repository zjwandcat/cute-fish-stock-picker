三步，开始使用

  1. 下载并完整解压选择系统版本。Mac 可将解压后的 .app 拖入“应用程序”。
  2. 双击打开Mac 打开“可爱鱼儿选股指南.app”；Windows 打开“启动选股指南.bat”。
  3. 填入 Tushare Token首次在浏览器设置页保存 Token。之后双击应用即可打开。

无需安装 Node.js、npm 或 Homebrew。Mac 关闭应用窗口或按 ⌘Q 即退出；Windows 关闭启动窗口即可。Token 和持仓保存在本机用户目录，更新版本会保留。申请 Tushare Token ↗

Mac 首次打开的安全提示

当前 .app 没有 Apple Developer ID 签名及公证。首次双击可能被拦截；请确认来自本项目，再到“系统设置 → 隐私与安全性”选择“仍要打开”。不需要关闭 Gatekeeper 或粘贴终端解锁命令。公司管理的 Mac 可能需要管理员批准。详细说明见 使用文档。

AI 研究和月度推荐是否直接可用？

行情和日常盯盘无需开发环境，但需联网及相应 Tushare 权限。AI 研究运行时已内置，默认关闭，启用前需自行配置模型 API Key；请求会发送至你配置的服务商，并可能收费。10q 月度推荐是独立可选功能，需要 Python、完整 10q 项目和数据，不包含在即开即用范围内。
